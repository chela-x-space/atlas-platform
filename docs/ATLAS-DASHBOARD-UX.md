# ATLAS Global Overview

The `/app` homepage is a situation-driven intelligence overview. Its hierarchy is:

1. Global Situation Now
2. Top Global Events
3. Hot Regions
4. Category Intelligence
5. Latest Verified Intelligence

All displayed event counts and rankings are derived deterministically from the existing dashboard snapshot. The overview shows explicit loading, unavailable, and empty states instead of substitute data.

The large globe/map visualization is no longer rendered on the homepage. The dedicated World Map remains available, unchanged, at `/app/map`.

Marketplace is a navigation destination only. `/marketplace` displays a minimal **Coming soon** placeholder. The dashboard contains no Marketplace products or promotions, and this change includes no commerce, purchasing, checkout, payment, licensing, wallet, download, creator, or NFT functionality.
